# The region table's classes (docs/region-table.md; docs/state-by-name-round.md 3.4):
# byte ranges of the quicksave's span with the class a reading gave them,
# ADDRESS LENGTH CLASS # why (source).
#
# The classes (round doc 3.4):
#   state    the game's logic state                          (a portable load writes it)
#   process  the process's own: exactly src/hook/snapshot.cpp's kKept, row for row (kept)
#   derived  rebuilt from state by a participant or by the next frames (as the participant says)
#   stack    the scheduler's words                           (written fresh)
#   unknown  read, and no class above fits or nobody has decided (written, and counted)
#
# A byte no row here covers takes its class from the table: `state` when a
# symbols.toml entry with a length names it, `unknown` when none does.
#
# tools/region_table.py refuses: two rows over one byte; a `process` row that is
# not a kKept range, or a kKept range with no `process` row; a byte of
# tools/statehash_skip.txt that no row here covers (every range the hash cannot
# see has been read, and its class says what the reading found). Add a row only
# with its source: a census row, a skip-list row, a ledger entry, a measurement.
# "census" below is docs/quicksave-census.md.
