**Breath of Fire III - bof3x v0.1.0-beta.2** - a player release, the second
beta. It carries two weeks of work since beta.1: a new launcher, a first
native Linux build, mods made from romhack patches, a solo-character mode,
the PlayStation's New Game screens, a 16:10 picture, and fixes from play.

bof3x is a renovation of the 2001 Chinese PC port of *Breath of Fire III*:
every function of the game's own code is our C++, our `bof3x.exe` runs it
with no code of Capcom's mapped, and the game can be installed from the PC
port, from a PlayStation disc alone, or from a PSP disc alone. **This
download holds no game data.** You add your own copy, and everything the game
reads is built on your machine from it.

## Getting started (Windows)

1. Unzip into a folder with a **short path**, e.g. `C:\Games\bof3x`.
2. Run `bof3x-launcher.exe`. The first time, it opens on the **Sources**
   page; later, it is under **Configure**, the **Data** tab.
3. On the **Sources** page, add what you own:
   - the PC port's game folder (the one holding `BOF3.exe` and `DAT`), the
     2001-04-18 Chinese release, unmodified;
   - a PlayStation disc as `.cue`/`.bin` - US, Japanese, European (English),
     French or German;
   - a PSP disc as `.iso` - Japanese or European;
   - or a `.zip` holding any of these;
   - or a whole folder of them: **Folder...** checks every image in it (and
     the folders below it) and adds each one that matches a known release.

   Each one is checked against the known releases by its files' hashes. The
   first source makes the install; each later one adds what it carries, and
   the install is rebuilt. Expect a few minutes per setup.
4. Play.

Everything is written inside the folder you unzipped. Your own files are
only read.

**Upgrading from beta.1 or an alpha:** unzip over the old folder and start
the launcher. It checks your install against the release. When a piece of
the install would be built differently, it names the pieces and offers to
rebuild them (**No** starts nothing and leaves the install as it is). The
rebuild keeps the parts that did not change: on two beta.1 installs it took
one to two minutes, and the saves and the settings were kept.

**Your saves.** The game's own save files are kept through every upgrade and
load as before. **A quicksave belongs to the build that made it:** a newer
build refuses to restore it and says so on screen (the file is not
touched). The 32-bit, the 64-bit and the Linux build refuse each other's
quicksaves the same way. Before you upgrade, make a game save.

## Getting started (Linux, new)

`bof3x-v0.1.0-beta.2-linux-x86_64.tar.gz` is a native build for x86-64
Linux. **It is new, and only its first scenes have been played.** One
person played the first scenes on one laptop (GNOME on Wayland): the
picture, the sound and the controls were right, and the story went on. On
ten scripted routes it computes the same game as the Windows builds, tick
for tick; one shop jingle's timing is the known exception. Installs from the
PC folder, from a US PlayStation disc alone and from a European PSP disc
alone, and the game's self-tests passed on a computer with no screen.
Nobody has played it further, or on another desktop or graphics card. If
you try it, please tell us what you see.

You need:

- a 64-bit Linux system with glibc 2.38 or newer (Ubuntu 24.04 or newer, or
  a system of the same age). The tarball's `README.txt` gives the exact
  versions;
- a Vulkan 1.3 graphics driver, and X11 or Wayland;
- Python 3.11 or newer with Pillow and capstone. The setup uses them. The
  tarball holds no Python;
- ffmpeg, optional, as on Windows.

To start:

1. Extract the tarball to a folder you can write to.
2. In that folder: `python3 -m venv runtime/python`, then
   `runtime/python/bin/pip install -r runtime/tools/requirements.txt`. On
   Debian and Ubuntu, `python3 -m venv` needs the package `python3-venv`.
   If there is no `runtime/python`, the launcher uses `python3` from your
   `PATH`.
3. Start `./bof3x-launcher` and add your copy of the game on the Sources
   page.

To check that your download is the file this project built (GitHub's CLI):

```
gh attestation verify bof3x-v0.1.0-beta.2-linux-x86_64.tar.gz --repo kerokline/BreathOfFire3PCPort
```

The Windows build also runs under Proton and Wine, as before.

## New since v0.1.0-beta.1

- **A new launcher.** The launcher draws its own window in place of the
  Windows dialogs. It is the same program on Windows and on Linux, with the
  same pages. It also has:
  - a **Function keys** page: each function action (quicksave, quick-load,
    the menu and the others) takes any key and a pad input;
  - a **save editor** for PC saves and PlayStation memory cards, with
    conversion between them;
  - a **Solo character** tab and a third **Cheats** page (below).
- **A PSP preset.** On the Preset page, **PSP** plays the game as the PSP
  release: it turns off the changes that go toward another release, and it
  sets the 16:9 picture, the PSP's art, data and sound where your install
  holds them, and the PSP's music.
- **A PSP disc's text beside the PC game.** An install from the PC folder
  and a PSP disc now holds that disc's language too: the European disc's
  English, or the Japanese disc's Japanese. A PlayStation disc of the same
  language is used first.
- **`BOF3.exe` is not read when you play.** The setup reads your PC copy
  once; after that, the game and the launcher's tools run without it.
- **Mods from romhack patches.** On the **Mods** tab, add a romhack's patch
  as the file its author released (`.xdelta` or `.ppf`, also inside the
  author's `.zip` or `.7z`). The mod is built on your machine from your own
  disc. A check box turns a mod off. Two patches are measured and known by
  name: *Breath of Fire III: Definitive Edition* 1.4 and *Better
  Descriptions* 1.1.1. A patch of the US disc is also built for the
  European English text when your install holds both.
- **Solo character** (off by default): play the game with one champion who
  fights alone, from a level-1 start at New Game. The field, the menus and
  the story are the original's; the shops, the masters and the Skill Notes
  show the champion alone.
- **The PlayStation's New Game screens:** the name entry and the options
  screen at New Game, in every language, read from your own disc. The
  faerie village's renamer uses the same grid.
- **A 16:10 picture** (384 x 240) for the Steam Deck and other 16:10
  screens, beside 16:9 and 21:9.
- **Smooth motion** (off by default, **experimental**): the Settings page's
  "Smooth motion: 60 frames each second" box shows a frame between each two
  of the game's frames. Nothing the game computes changes.
- **Cheats** (off by default):
  - **Learn:** an examining member always learns the enemy's skill;
  - **Faerie village speed:** a slider, 0 to 10, for how fast the village
    works;
  - under **No-fail minigames**, Parch's item seller stocks the shisu's
    ingredients.
- **Movies and jingles from a PlayStation disc** are decoded by the game's
  own decoders: the logo movie and the 11 jingles no longer need ffmpeg.
  The PC movie's repair and the PSP's sound and movie still use your ffmpeg.
- **Fixes:**
  - a whole-party heal on the world map now heals a leader who is not Ryu;
  - a late frame no longer leaves the frame after it unshown;
  - at 21:9: the big tree in one area no longer vanishes when half of it is
    in the picture, one camp is no longer pillarboxed, the sea bridge's far
    end is drawn, a sprite already seen is kept, and a list's highlight no
    longer slides;
  - the save slot's EXP bar is drawn inside its frame;
  - a Japanese name with a paired character shows whole in two battle
    windows;
  - the save editor sees a running game again;
  - under Proton, the shaders no longer need a compiler in the prefix, and
    large files open;
  - Windows now reads the signature of `bof3x.exe`. In beta.1 the file was
    signed, but Windows showed it as not signed.
- **Smaller downloads.** The programs no longer hold their debug
  information. It is in the `-symbols.zip` files, which are for developers.
- **A 64-bit build** ships beside the 32-bit one as
  `bof3x-v0.1.0-beta.2-win-x64.zip`. It is a **developer build**. The 32-bit
  zip is the default.

## ffmpeg (optional, recommended)

The PSP's sound effects, voices and logo movie, and the repair of the PC
port's logo movie (Indeo 5, which current Windows cannot play) are
converted by **your** ffmpeg. Get a build from
<https://ffmpeg.org/download.html>, then put it on your `PATH` or locate it
in the launcher, and run the setup again. Without it those pieces are
skipped and the setup says which.

## What works

- Installs from the PC port, from any one catalogued PlayStation disc alone,
  from a PSP disc alone, or a mix; English, French, German and Japanese from
  the matching disc, and any two of them together as a row above the text.
- A full play to the ending and the clear save, by hand (beta.1's two
  plays).
- The PlayStation's sequenced music from your disc, the PSP's, or the PC's
  MP3s; the Jukebox in the launcher.
- Quicksaves alongside the game's own saves, in the field and in battle.
- Presets, and single changes turned off by name.
- Direct3D 11, windowed or borderless fullscreen, integer scaling, widescreen
  (16:10, 16:9 and 21:9), the point filter and CRT looks, modern pads
  through SDL3, sound through SDL3.
- Signed Windows executables (Authenticode, timestamped); a build
  attestation for the Linux tarball.
- The fixes and options listed in the project's README, each recorded in
  `docs/DIVERGENCE.md`.

## Known issues

- **Issue #190, a crash at the dragon gene window in battle.** It was not
  reproduced, and the issue is closed. **If it happens to you,** add a
  comment to issue #190: the
  `CRASH n:` lines from `bof3x.log` in your folder, what the Sources page
  lists, and your language. **Do not attach the `bof3x.crash-*.dmp`
  files**: they hold the game's data.
- **A mod added before this release** from the Definitive Edition's patch:
  remove it and add the patch again, so that it gets the new behaviours.
  The same holds for *Better Descriptions* added before 2026-11-15.
- **Furigana does not build from this release** (SudachiPy is not bundled),
  and its readings are not proofread.
- At 21:9 a menu box that slides in can be seen whole in the side band on
  its first frames.
- Some labels and text painted into artwork stay Chinese on a PC-based
  install.
- **Not read yet:** `.chd` and `.cso` images (convert them back to
  `.cue`/`.bin` or `.iso`), and 2048-byte `.iso` images of a PlayStation
  disc - use the `.bin`/`.cue`.
- **Linux:** a PSP install made without ffmpeg has no effects, voices or
  logo movie, as on Windows.
