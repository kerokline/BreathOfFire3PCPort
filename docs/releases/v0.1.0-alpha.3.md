**Breath of Fire III - bof3x v0.1.0-alpha.3** - a player release, an alpha.

bof3x is a renovation of the 2001 Chinese PC port of *Breath of Fire III*:
every function of the game's own code is our C++, our `bof3x.exe` runs it
with no code of Capcom's mapped, and the game can be installed from the PC
port, from a PlayStation disc alone, or from a PSP disc alone. **This
download holds no game data.** You add your own copy, and everything the game
reads is built on your machine from it.

## Getting started

1. Unzip into a folder with a **short path**, e.g. `C:\Games\bof3x`. Windows
   cannot play the opening movie from a path of about 160 characters or more.
2. Run `bof3x-launcher.exe`. The first time, it opens on the **Sources**
   page; later, it is under **Configure**, the **Data** tab.
3. On the **Sources** page, add what you own:
   - the PC port's game folder (the one holding `BOF3.exe` and `DAT`), the
     2001-04-18 Chinese release, unmodified;
   - a PlayStation disc as `.cue`/`.bin` - US, Japanese, European (English),
     French or German;
   - a PSP disc as `.iso` - Japanese or European;
   - or a `.zip` holding any of these;
   - or a whole folder of them: **Folder...** checks every image in it (and
     the folders below it) and adds each one that matches a known release.

   Each one is checked against the known releases by its files' hashes, and
   told apart in one line if it is not one. The first source makes the
   install; each later one adds what it carries (its language, the PSP's
   extras), and the install is rebuilt. Expect a few minutes per setup.
4. Play.

Everything is written inside the folder you unzipped: `sources.toml`,
`cache\` and `game\`. Your own files are only read.

**Upgrading from alpha.1 or alpha.2:** unzip over the old folder, then open
**Configure**, **Data**, **Sources...** and press **Build the install**
again. A disc-built install made by an earlier release is refused at start
with a message saying so (two of this release's fixes change what the
importer builds); rebuilding takes a few minutes and keeps your saves.

## New since v0.1.0-alpha.2

- **The files are signed.** `bof3x-launcher.exe`, `bof3x.dll` and `bof3x.exe`
  carry an Authenticode signature with a timestamp, and each has a version
  block (right-click, Properties, Details). Antivirus heuristics had scored
  the unsigned executable as suspicious for its unusual layout, which the
  engine needs; a signed, named file is what those checks want. Windows
  SmartScreen may still warn on the first downloads while the publisher is
  new to it - that fades with time, not with a setting.
- **PlayStation-only install: the inn and the camp no longer hang** on a
  black screen. The rest jingles were the PC port's MP3s and not on the disc;
  a missing sound now ends its wait, and with ffmpeg present the setup makes
  the 11 jingles from the disc's own audio.
- **Fishing on a disc-built install:** the Rule pages, the counter and the
  equipment headings read right (they were stacked, zero or blank). The
  fishing spot is reachable on a PlayStation-US install for the first time.
- **Save and load slots** on a disc-built install no longer draw stray text
  beside the slot number.
- **The child's field sprite** in the forest after the mine drew in pieces on
  a disc-only install; it is whole.
- **Frames that held for seconds** on a busy disk: the game's log is written
  off the game thread, so a slow drive cannot stall a frame.
- **Old caches are refused, not crashed on:** an install built before these
  fixes stops at start with a message to rebuild it, instead of crashing on
  entering the world map.

## ffmpeg (optional, recommended)

The opening logo movie from a disc, the PSP's sound effects and voices, the
PlayStation-only install's rest jingles, and the repair of the PC port's
logo movie (Indeo 5, which current Windows cannot play) are converted by
**your** ffmpeg. Get a Windows build from
<https://ffmpeg.org/download.html#build-windows>, then put it on your `PATH`
or locate `ffmpeg.exe` in the launcher, and run the setup again. Without it
those pieces are skipped and the setup says which; the inn still works, in
silence.

## What works

- Installs from the PC port, from any one catalogued PlayStation disc alone,
  from a PSP disc alone, or a mix; English, French, German and Japanese from
  the matching disc.
- The PlayStation's sequenced music from your disc, or the PC's MP3s; the
  Jukebox in the launcher.
- Direct3D 11, windowed or borderless fullscreen, integer scaling, widescreen
  (16:9 and 21:9), the point filter and CRT looks, modern pads through SDL3.
- The fixes and options listed in the project's README, each recorded in
  `docs/DIVERGENCE.md`.

## Watched, not yet played through

This is an alpha. Much has been run by scripts and watched rather than played
by hand:

- **The disc-only and PSP-only installs** (new in October 2026) have passed
  scripted runs and the attract sequence, not a playthrough. Of this
  release's disc fixes, only the PlayStation-US build has been played; the
  other discs' are checked by recipe.
- **The setup** (the Sources page, the bundled importer) has been used on the
  developer's machine for each kind of source; the launcher side has not yet
  been used by anyone else.
- French, German and Japanese are less tested than English.
- **The launcher window** has been seen at 100 % display scaling only; at
  125 % or 150 % its picture is smoothed rather than sharp.

## Known issues

- PSP-JP: a crash about one run in five at the fishing banner (D279).
- Some labels and text painted into artwork stay Chinese on a PC-based
  install.
- **Not read yet:** `.chd` and `.cso` images (convert them back to
  `.cue`/`.bin` or `.iso`), and 2048-byte `.iso` images of a PlayStation disc,
  which have lost the disc's audio and movie sectors - use the `.bin`/`.cue`.
- The first setup takes several minutes and about 1 GB of disk for a disc
  install (the cache and the game folder).
